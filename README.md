# Общее описание

Программа представляет собой имитационную модель помеховой обстановки, воздействующей на радиолокатор с синтезированной апертурой космического базирования (РСА КБ). Позволяет подмешивать помеховый сигнал к радиоголограммаме (РГГ) с заданными параметрами.
В версии 1.3 реализованы два типа помехового сиганала:
1. Гармонический
2. ЛЧМ


# Исполняемый файлы

В __dist__ находится SAR Jammer.exe - файл для запуска программы.

# Исходный код

В _source_code/_ содержатcя исходные файлы в папке __src/__ и список зависимостей __requirements.txt__.

# Установка зависимостей

Для устанвоки зависимостей откройте терминал и укажите путь до папки с файлами, далее создайте виртуальное окружение:

```
python -m venv venv # Windows

python3 -m venv venv # macOs/Linux
```

Активируйте виртуальное окружение:

```
venv/Scripts/activate.bat # Windows

source venv/bin/activate
```

Установите зависимости из файла requirements.txt:

`pip install -r requirements.txt`
